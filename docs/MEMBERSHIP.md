# 成员申请与只读权限

## 好友与私聊

成员侧栏「好友」：

- 按用户名搜索成员
- 发送好友申请
- 接受 / 拒绝
- 删除好友
- 拉黑 / 解除拉黑
- 好友备注：只有自己能看到
- 一对一私聊

管理员也可以被加为好友，并进入自己的好友私聊。

私聊规则：

- 只有已接受好友之间可以发消息
- 支持文字和图片
- 图片支持拖入、粘贴、选择文件
- 单张图片最大 10MB
- 图片保留 7 天，过期自动清理；文字保留
- 自己消息蓝色，管理员消息绿色，其他成员普通样式

管理员在「账号管理 → 私聊」按会话查看所有成员私聊。  
成员界面已明确提示：**管理员可查看私聊内容**。

## 更新公告

成员侧栏「更新公告」只显示与成员相关的条目；管理员能看到全部条目。

## 账号管理

管理员左侧「账号管理」一个页签，内含：

```text
用户
注册申请
邀请码
信箱
```

用户页可以：

- 查看用户名
- 看角色（管理员 / 只读成员）
- 看状态（正常 / 已停用）
- 给每个用户写**管理员备注**
- 停用 / 启用普通成员
- 生成一次性临时密码并重置成员密码
- 删除成员账号
- 勾选多个账号批量停用 / 启用 / 删除

保护：

- 不能停用/删除当前登录的管理员自己
- 不能删除最后一个管理员
- 停用或重置密码会立即清除该用户已有会话
- 删除账号不会删除历史聊天和信箱记录

旧地址仍可用，会自动跳到对应页签：

```text
/requests → /accounts?tab=requests
/invites  → /accounts?tab=invites
/mailbox  → /accounts?tab=mailbox
```

聊天室仍然是独立入口。

## 流程

```text
访客打开 /apply
→ 填用户名、密码、申请说明
→ 进入 pending 申请队列
→ 管理员在 /requests 审批
→ 通过后创建 reader 账号
→ 申请人用申请时的用户名/密码登录
→ 进入成员只读空间
```

管理员审批页：

```text
/admin → 注册申请
```

## 角色

### admin

完整管理权限：页面、模块、知识库、素材库、设置、AI。

### reader

只读：

- 公开页面
- `visibility = members` 的知识库条目
- 公开页面里已经引用的图片

不能：

- 编辑页面 / 上传 / 删除
- 访问管理员知识库、草稿、未引用素材
- 访问 `/api/bootstrap`、`/api/kb`、`/api/assets` 等管理接口
- 使用管理员 AI
- 管理用户或审批申请

## 知识库可见范围

成员只能看到：

```text
status = published
```

草稿、待审、归档条目不可见。  
**所有已发布条目都会对成员可见**，所以内部内容不要发布。

## 成员素材库

只显示：

- 公开页面 blocks 里引用的图片
- 不显示未引用文件
- 不显示站点 Logo、模块图标、管理用素材

## 聊天室

- 只有 admin 和已审批 reader 能进入
- 所有成员共用一个聊天室
- 管理员也可以发言
- 前端每 4 秒轮询一次
- 单条最多 1000 字，每用户每分钟最多 10 条

## 信箱

- 成员可以向管理员发送建议
- 管理员在「信箱」查看未读/全部
- 管理员可以直接回复建议，回复后成员能在自己的信箱里看到
- 回复后自动标记已读
- 单条最多 3000 字，每用户每小时最多 5 条
- 每条建议保留一条可修改的回复

## 邀请码

管理员在「邀请码」页：

- 点一次生成 10 条
- 每个邀请码一次性使用
- 使用过的邀请码显示删除线
- 最多保留 50 条可见邀请码
- 超过 50 条时优先隐藏最近使用过的邀请码
- 如果未使用码仍然超标，删除最旧的未使用码

申请人可以在 `/apply` 填邀请码：

```text
有有效邀请码 → 立即创建 reader 账号并激活
没有邀请码 → 进入 pending 审批队列
```

## 防刷

- 公开申请页有蜜罐字段
- 同一 IP 3 次/小时
- 全站 50 条申请/24 小时
- 密码使用 scrypt
- 申请写入 `registration_requests`，不直接创建账号
- 管理员审批后才创建用户
- 邀请码一次性，验证后立即作废

## 当前没有做

- 邮件验证（没有配置 SMTP）
- Turnstile / 图形验证码（需要申请站点 key）
- 自动通知申请人（需要邮件/短信）
- 封禁/删除成员的管理 UI
- 私密模块对成员开放

## 测试

```text
1. /apply 提交申请
2. 管理员 /requests 看到 pending
3. 审批通过
4. 申请人登录 → 进入只读成员页
5. 成员看不到 admin 可见知识库
6. 成员 /api/kb、/api/assets、/api/bootstrap 返回 403
7. 成员 /kb、/assets 正常
8. 公开页面图片可用；未引用图片 /api/public/assets 返回 404
```
