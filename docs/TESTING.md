# 测试规程

## 判定标准

### 小功能

只改一个独立交互、单个接口或单个样式时：

1. `tsc --noEmit`
2. `vite build`
3. 对改动点做一次真实浏览器健全性测试
4. 确认没有新增未处理页面异常

### 大改

涉及保存、编辑器、导入、权限、数据库、路由、部署或多个功能联动时：

1. 编译 + 构建
2. **冒烟测试**：登录 → 打开页面 → 编辑 → 保存 → 刷新 → 切页 → 回看
3. **逐功能健全性测试**：每个受影响功能单独跑一遍
4. 记录通过/失败，不允许只看“能打开”
5. 失败项修完后重跑受影响项，再跑一遍冒烟

## 功能健全性清单

### 编辑器

- [ ] 新建页面
- [ ] 输入文字，700ms 后自动保存
- [ ] 刷新后内容仍在
- [ ] 切换到别的页面再回来，内容仍在
- [ ] 标题编辑：清空不自动复原、失焦处理正确
- [ ] 加粗、斜体、下划线、删除线
- [ ] 文字颜色生效
- [ ] 文字颜色不改变超链接颜色
- [ ] 列表、任务、引用、代码块、表格
- [ ] 图片：插入、保存、刷新后仍在
- [ ] 保存失败时出现错误提示，本地草稿可恢复

### Markdown

- [ ] 导入为子页面
- [ ] 覆盖当前页面
- [ ] 覆盖后标题保留
- [ ] 表格、列表、代码块、图片链接解析正常

### 文档可靠性

- [ ] 大文档（100+ 块）保存、刷新、切换页面
- [ ] 保存请求失败后切页，回来能恢复草稿
- [ ] 草稿恢复后能重新保存到服务端
- [ ] 异常表格/图片数据不会打崩整页

### 知识库 / AI

- [ ] 知识库列表、搜索、发布、归档
- [ ] AI 只检索已发布条目
- [ ] MCP token 检索、提交草稿
- [ ] AI 来源跳转

### 素材库

- [ ] 上传笔记图片 → 素材库显示「笔记图片」
- [ ] 上传模块图标 → 素材库显示「模块图标」
- [ ] 上传站点 Logo → 素材库显示「站点 Logo」
- [ ] 没有页面/图标引用的上传 → 显示「未引用」
- [ ] 分类筛选、数量统计、预览、复制地址正常
- [ ] 勾选未引用文件可单独删除
- [ ] 「一键删除未引用」只删除未引用文件
- [ ] 选中正在使用的文件时服务端跳过，不破坏页面/图标

### 成员申请

- [ ] `/apply` 可提交申请
- [ ] 管理员 `/requests` 看到待审批
- [ ] 审批通过后能用申请密码登录
- [ ] reader 不能进入管理员 Shell
- [ ] reader 只能看已发布知识库（草稿不可见）
- [ ] reader 只能看公开页面引用素材
- [ ] reader 访问管理接口返回 403

### 聊天室 / 信箱 / 邀请码

- [ ] reader 能进入聊天室并发言
- [ ] admin 能看到 reader 的消息
- [ ] reader 能发建议，admin 能看到未读
- [ ] admin 能标记建议已读
- [ ] admin 能回复建议，成员信箱显示回复
- [ ] 管理员一次生成 10 条邀请码
- [ ] 邀请码一次性使用，使用后显示删除线
- [ ] 超过 50 条时优先隐藏最近使用的已用码
- [ ] 没有邀请码仍进入管理员审批队列

## 记录要求

每次大改至少记录：

```text
改动范围：
冒烟结果：
逐项结果：
未通过项：
已知风险：
部署版本：
```

## 当前已知风险

- 多标签页同时编辑是最后写入覆盖，没有版本冲突锁。
- 服务端单页内容上限 5MB，超大文档会被拒绝。
- 图片放进表格单元格无法作为图片保留，会降级为 `[图片]` 文本。
- 保存失败时图片文件可能已上传但页面未引用，形成孤立附件。
- 部署后旧标签页可能加载到旧资源，需要硬刷新。
