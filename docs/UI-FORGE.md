# Forge UI 统一

2026-11-25 起，默认工作台统一为 Forge 风格。

## 视觉

- 背景 `#111111`，面板 `#181818`
- 品牌强调色 `#f16436`（锻造橙）
- 圆角 6px，细边框，低阴影
- 移除背景网格、径向渐变、荧光绿
- 默认 Dashboard 改为内容优先：最近三篇文档 + 模块网格

## 主题迁移

旧版 Forge 主题的默认荧光绿：

```text
#c8f76a
```

会被 `normalizeTheme()` 自动迁移为：

```text
#f16436
```

同时把圆角降为 6px，关闭网格和环境光。显式自定义过的强调色不受影响。

数据库迁移 v16 会把旧默认模块色 `#c8f76a` 更新为 `#f16436`。

## 侧栏模块拖动

- 「我的模块」中的顶层模块可以拖动排序
- 按住左侧手柄拖动，顺序写入 `POST /api/modules/reorder`
- 只改变顶层模块顺序，不影响子模块和页面
- 拖动结束显示 toast
- 键盘无障碍：模块菜单仍有上移/下移

## 聊天 emoji

聊天室和好友私聊都使用系统原生 Unicode emoji，不依赖外部图片或字体授权。

- 点击笑脸打开
- 分：表情 / 手势 / 游戏 / 日常 / 符号
- 选中的 emoji 插入输入框
- 不属于自定义 emoji 包，因此没有第三方素材授权问题
